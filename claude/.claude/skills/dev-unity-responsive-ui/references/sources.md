# Sources

## Official Unity 6.3 documentation

- [Canvas Scaler](https://docs.unity3d.com/6000.3/Documentation/Manual/script-CanvasScaler.html): scaling modes, reference resolution, Match, Expand, and Shrink behavior.
- [Designing UI for Multiple Resolutions](https://docs.unity3d.com/6000.3/Documentation/Manual/HOWTO-UIMultiResolution.html): Canvas scaling and anchor-based adaptation across aspect ratios.
- [Basic Layout](https://docs.unity3d.com/6000.3/Documentation/Manual/UIBasicLayout.html): RectTransform anchors, pivots, and offsets.
- [Screen.safeArea](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Screen-safeArea.html): safe rectangle in screen pixels with a bottom-left origin.
- [Aspect Ratio Fitter](https://docs.unity3d.com/6000.3/Documentation/Manual/script-AspectRatioFitter.html): Fit In Parent, Envelope Parent, and pivot-dependent resizing.
- [Auto Layout](https://docs.unity3d.com/6000.3/Documentation/Manual/UIAutoLayout.html): layout controllers and layout elements.
- [Content Size Fitter](https://docs.unity3d.com/6000.3/Documentation/Manual/HOWTO-UIFitContentSize.html): content-driven sizing and pivot behavior.
- [Device Simulator device definitions](https://docs.unity3d.com/6000.3/Documentation/Manual/com.unity.device-simulator.devices.html): simulated device definitions used for screen testing.

This package targets Unity 6.3. Use the version-matched Unity 6.3 pages and exact installed package documentation for every version-sensitive API.
