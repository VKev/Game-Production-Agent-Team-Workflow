# Cinemachine sources

Use the installed pinned Cinemachine 3 package documentation and source first.

- [Cinemachine 3.1 manual](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/index.html): current 3.1 concepts and navigation.
- [Install and upgrade Cinemachine](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/InstallationAndUpgrade.html): Unity Package Manager installation and supported upgrade path.
- [Cinemachine Brain](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineBrain.html): camera selection, blends, update methods, and Timeline control.
- [Cinemachine Camera](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineCamera.html): the Cinemachine 3 camera component and target model.
- [Camera transitions](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/concept-camera-control-transitions.html): priorities, activation, cuts, and blends.
- [Input Axis Controller](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineInputAxisController.html): Cinemachine 3 input-axis ownership.
- [Cinemachine Confiner 3D](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineConfiner3D.html): confining camera position to a volume.
- [Unity 6.3 Package Manager Client API](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/PackageManager.Client.html): installed-package inspection.

The `@3.1` pages are a documentation stream, not a substitute for the exact resolved package version.
