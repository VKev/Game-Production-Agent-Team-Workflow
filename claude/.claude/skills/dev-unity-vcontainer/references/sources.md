# Sources

- [Official VContainer repository](https://github.com/hadashiA/VContainer): package source, releases, license, features, installation examples, and exact package layout.
- [Official installation guide](https://vcontainer.hadashikick.jp/getting-started/installation): supported Unity version, OpenUPM installation, official Git URL format, and manual package option.
- [Official package manifest](https://raw.githubusercontent.com/hadashiA/VContainer/master/VContainer/Assets/VContainer/package.json): current package ID, version, Unity floor, and documentation metadata.
- [Hello World](https://vcontainer.hadashikick.jp/getting-started/hello-world): basic `LifetimeScope`, registration, and resolution workflow.
- [Constructor injection](https://vcontainer.hadashikick.jp/resolving/constructor-injection): constructor selection, `[Inject]`, stripping, and component limitations.
- [Registering MonoBehaviour](https://vcontainer.hadashikick.jp/registering/register-monobehaviour): scene, hierarchy, prefab, and component registration behavior.
- [Plain C# entry points](https://vcontainer.hadashikick.jp/integrations/entrypoint): Unity lifecycle integration for non-component classes.
- [Lifetime overview](https://vcontainer.hadashikick.jp/scoping/lifetime-overview): Singleton, Scoped, Transient, parent-child lookup, and disposal behavior.
- [Project root LifetimeScope](https://vcontainer.hadashikick.jp/scoping/project-root-lifetime-scope): application-root configuration and cross-scene scope behavior.
- [UniTask integration](https://vcontainer.hadashikick.jp/integrations/unitask): async entry points and PlayerLoop integration.
- [Diagnostics window](https://vcontainer.hadashikick.jp/diagnostics/diagnostics-window): container inspection and dependency diagnostics.
- [Source Generator](https://vcontainer.hadashikick.jp/optimization/source-generator): optional generated injection paths and build considerations.

Use the installed package source for exact APIs. The online `master` documentation can be newer than a project-pinned release.
